# 花事 Huashi

一份关于花的数字视觉小杂志，教人从轮廓、颜色和感受开始看花。

> 花很好看。但你知道它为什么好看吗？

## 内容

- 第一章「开始看花」：形、色、气三个观察动作，以及“先别看名字”看花练习
- 第二章「花的十二种性格」：12 种花，每种包含主图与细节、性格、观察、编辑手记、花语、故事
- 「花店里的它们」：6 组花店大花束摄影与 10 种常见花材
- 第三章「花与人的事」：12 种情绪，从“你想让 TA 感受到什么”出发推荐花
- 尾声：首尾呼应，回到“下次路过一朵花，先看一会儿”
