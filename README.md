# 花事 Huashi

一份关于花的数字视觉小杂志，先让人欣赏花束，再慢慢认识花。

> 一束花，是最接近美的样子。

## 它是什么

- v2.0 教人看懂花：形、色、气三种观察方式，12 种花的性格与故事
- v2.1 让人用花表达：三步测试、推荐结果、我的花事
- v2.2 让“看花”本身成为体验：首页节奏、花卉详情分层阅读、花与花之间的推荐关系
- v2.3 让花留在记忆里：我的花事升级为时间线，可以补写和修改与花有关的记忆
- v2.4 让花束成为灵感：10 束花组成提示词画廊，每束配一句可复制的生成提示词
- v2.5 让十二种性格成为季节图鉴：四季四套版式，每朵花有大号编号与印章式性格
- v2.6 让整站成为一册墨色植物图鉴：近黑底色、深苔绿与淡绯色点缀，花图统一压暗降饱和，四季版页更克制，花束画廊扩充到 16 束
- v3.0 让这册墨色植物图鉴正式发布到 GitHub，作为可以随时打开和继续生长的数字花园
- v4.0 让整站从“介绍花”变成“欣赏花”：花束成为主角，单花与知识收进花束档案，测试改为推荐一束花

## 内容

- 首页：一束花占据整屏，只有刊名与一句邀请
- 花束美术馆：16 束花以大幅版面出现，每束配名字、情绪、一句话与可复制的生成提示词
- 花束档案：点开任一花束，看到大图、花材拆解、为什么好看、故事与提示词
- 送花时刻：三步测试（送给谁、想说什么、希望什么感觉），推荐一束花而不是一朵花
- 我的花事：花事时间线，记录花束、日期与一句话，可以补写、修改或放下某段记忆
- 尾声：回到“下一次路过花店，先停一会儿”
