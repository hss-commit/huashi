# 花事 Huashi

一份关于花的数字视觉小杂志，教人从轮廓、颜色和感受开始看花，也慢慢学会用花表达自己。

> 花很好看。但你知道它为什么好看吗？

## 它是什么

- v2.0 教人看懂花：形、色、气三种观察方式，12 种花的性格与故事
- v2.1 让人用花表达：三步测试、推荐结果、我的花事
- v2.2 让“看花”本身成为体验：首页节奏、花卉详情分层阅读、花与花之间的推荐关系
- v2.3 让花留在记忆里：我的花事升级为时间线，可以补写和修改与花有关的记忆

## 内容

- 首页：只保留刊头、花事、核心问题与“开始看花”
- 第一章「开始看花」：形、色、气三个观察动作，以及“先别看名字”看花练习
- 第二章「花的十二种性格」：12 种花，详情页按“看见 → 观察 → 理解 → 认识 → 花语 → 故事”分层阅读，并推荐 3 朵相似的花
- 「花店里的它们」：6 组花店大花束摄影与 10 种常见花材
- 第三章「花与人的事」：三步测试（给谁、想说什么、希望什么感觉），每次只问一个问题
- 「我的花事」：私人花册升级为花事时间线，记录花名、日期与一句话，可以补写、修改或放下某段记忆
- 尾声：首尾呼应，回到“下次路过一朵花，先看一会儿”
